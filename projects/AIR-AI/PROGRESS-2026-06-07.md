## NEW: Hybrid Session Engine

**File:** `app/hybrid_session.py`

### Components

1. **FFTSymbolicAnalyzer**
   - Converts query text to 2D symbolic field
   - Computes spectral features (center energy, symmetry, entropy, radial profile)
   - Generates mystical/sci-fi/clinical interpretations

2. **RMCEngine** (Recursive Meta-Cognition)
   - Decomposes input into sub-components
   - Estimates confidence for each sub-result
   - Synthesizes best results with explainable routing

3. **Biorhythm/Thought Matrices**
   - 12×12 biorhythm interaction matrix
   - 6×6 thought interaction matrix
   - Projection from biorhythm space to thought space

4. **HybridSessionEngine**
   - Orchestrates FFT → Matrices → RMC → Response
   - Lore cache integration (loads from `Rememberence/` directory)
   - Multiple flavor modes (mystical, sci-fi, clinical, quantum)

### New Endpoint

```
POST /oracle/hybrid
{
    "query": "What lies ahead?",
    "character": {
        "animal_sign": "Dragon",
        "star_sign": "Scorpio",
        "species": "Human",
        "type": "Warrior"
    },
    "flavor": "mystical"
}
```

Returns complete session with FFT analysis, matrices, RMC confidence, and lore-matched response.

### 1. Donjon Generators Ported to Python

  - Functions: `generate_name()`, `generate_list()`, `generate_npc()`

- **`generators/donjon/text.py`** - Template-based text generator
  - Templates: tavern names, shop names, quest hooks, room descriptions
  - Functions: `generate_tavern()`, `generate_shop()`, `generate_quest()`, `generate_room()`
  - Test output: Working ✓

### 2. Oracle Calculations Module
- **`app/oracle_calculations.py`** - Core mechanical calculations
  - **Biorhythm Calculation:** 12 stats from Animal + Star signs
  - **Thought Generation:** 6 thoughts from biorhythm pairs + State
  - **Combat Stats:** HP, ATK, DEF, SPD, MP from species/type/level/tier
  - **Dice Rolling:** d20 with modifiers, arbitrary dice notation (3d6+2, etc.)
  - **Oracle Debt Tracking:** Per-seeker, per-topic debt with decay
  - **Character Creation:** Full `create_character()` helper
  - Test output: Working ✓

### 3. Flask Server Updated
- **`app/app.py`** - Complete Oracle API server
  - **State Management:** `/save`, `/load`, `/clear`
  - **Oracle Endpoints:**
    - `POST /oracle/consult` - Consult with question, optional signs
    - `GET /oracle/fragment` - Random d100 fragment
    - `GET /oracle/debt/<seeker_id>` - Check debt status
  - **Generator Endpoints:**

    - `GET /generate/shop` - Shop description

    - `GET /generate/room` - Room description

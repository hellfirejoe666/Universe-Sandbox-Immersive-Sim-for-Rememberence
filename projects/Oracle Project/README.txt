### Quick Start – Three Steps to Awaken the Oracle

1. **Create a new Grok Project**  
   Go to https://grok.com → New Project (top-right corner)  
   Give it any name you like (example: “Rememberence Oracle”)
   Copy/paste the contents of the Project Instructions file to the instructions field.
   Save / Apply

2. **Add ALL the project files**  
   Upload every file provided in the Project Files folder to your project files.
   Grok needs these documents visible in the conversation to parse constants, run simulations, and stay canon-aligned.

3. **Paste the Custom Instructions**  
   In the chatbar, click the mode selector dropdown (where it says “Auto” / “Fast” / “Expert” etc.)  
   Choose **Custom Instructions**  
   Delete any existing text  
   Copy/paste the contents of the Custom Instructions file into this instruction field.
   Save / Apply

4. **Begin the journey**  
   In the chat, type:  
   **Awaken Oracle.**

The Oracle will greet you and guide you into character creation, exploration, combat, or chronicle-weaving — at your pace.
